# 腾讯云 Token Plan 一键接入

> 就一个文件，双击就能用。

---

## Mac 用户

把 `setup.command` 存到桌面 → **双击** → 选套餐 → 输 Key → 完成。

> 如果提示"无法打开"：系统设置 → 隐私与安全性 → 仍要打开。

## Windows 用户

把 `setup.py` 存到桌面 → **右键 → Python 打开** → 选套餐 → 输 Key → 完成。

---
